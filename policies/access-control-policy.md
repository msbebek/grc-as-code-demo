# Access Control Policy (demo)

Version 1.0 | Owner: IT Security | Review: annually, changes only through a reviewed pull request

1. Access is granted on a need-to-know basis and approved by the application owner.
2. Privileged access needs a named owner and a documented business reason (control AC-02).
3. All user access to in-scope applications is reviewed quarterly (control AC-01).
4. Access of leavers is removed within 2 business days of termination (control AC-03).
5. Conflicting roles are not combined without a documented mitigating control (control AC-04).
